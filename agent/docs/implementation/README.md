# 복지 추천 구현 단계

## 최신 화면: HERMES Complete

[Step 06](step06/README.md): 사용자 제공 완성 HTML을 기본 화면으로 교체했다. 기존 모델 API·추천 그래프를 연결하고 첨부 보관 자료와 브라우저 기록을 구분한다. Step 05 화면은 legacy 모드로 보존한다.

## 현재 진행: 화면설계서 적용

[Step 05](step05/README.md): HERMES 6개 화면을 구현하고 실제 근거·공통 추천 그래프·브라우저 검토 이력을 연결했다. 아래 단계별 미완료 표시는 당시 기록이다. 현재 그래프·API·웹 연결은 구현됐으며, 공식 복지사업 DB·자유형 LLM 대화·서버 공동 이력은 후속이다.

## 최신 진행: 그래프·API·화면

[Step 04](step04/README.md): 기본 final 화면에서 지역 선택 → 공통 추천 그래프 → API → 후보·제외·보류 표시 연결.
실제 자료 API 200, API 테스트 4개, TypeScript/Vite 빌드, 브라우저 월 변경 시 결과 갱신을 확인했다.
이하 ‘API·웹 미완료’는 이전 단계 이력이다. 기존 조사 그래프 어댑터 연결과 별도로 레거시 전체 실행 회귀는 남아 있다.

## 최신 진행: 실제 근거 추천 연결

[Step 03 README](step03/README.md): 실제 I5·활동 번들 → 연구용 조합 → ERD 임시 DB → 추천/제외/보류를 구현했다.
강남구 2025-08 MAN 20G 실행: 후보 2건, 제외 1건, 보류 1건. 복지사업은 가상 자료다.
I5 고저 임계값은 적용하지 않는 context 모드이며 명시적 opt-in이 필요하다.
LangGraph·API·웹 연결은 미완료다. 아래의 실제 지표 연결 미완료 표시는 Step 02 당시 이력이다.

## 최신 변경: ERD v2

2026-10-25 사용자 선택으로 9개 내부 태그에서 **공식 API 분류 + 별도 I5 연결**로 전환했다.
[Step 02 ERD v2](step02/ERD_V2.md)에 변경 구조·실행 방법·제약을 기록했다.
새 임시 DB 14테이블, 가상 5건의 검색·조건 검토가 실행된다. 실제 I5/V3 및 그래프 연결은 미완료다.
아래 Step 01/02의 9태그 구현은 이전 시연 이력이며 신규 분류 계약으로 사용하지 않는다.

## 순서

에이전트의 계약·결정적 처리 → 실제 원천/복지 DB 어댑터 → 조사 그래프 → 서비스 API → 웹 화면 순서로 진행한다. 웹에서 판단 로직을 중복 구현하지 않는다.

| 단계 | 내용 | 상태 |
|---|---|---|
| 01 | 9태그 계약·삼값 조합 규칙·사업 필터·추천 이유 | 구현, 합성 단위시험 8개 통과 |
| 02 | 임시 SQLite 복지 DB 및 검색 어댑터 | 합성 16건 연결, 누적 시험 11개 통과. 실제 I5/V3·공식 DB 연결은 미완료 |
| 03 | 실제 I5·활동 → ERD 임시 DB 추천 | 구현, 실제 근거·가상 사업으로 검증 |
| 04 | 공통 그래프·API·기본 화면 | 구현, API 시험 4개 통과. 운영 권한·레거시 전체 회귀는 후속 |
| 05 | HERMES 화면설계서 6장 적용·근거·이력 | 구현, 추천 그래프 연결 및 브라우저 검증. 규칙형 대화·로컬 기록 |

각 단계는 하위 README에 입력·처리·출력·실행 검증·미완료 항목을 남긴다. 기능 코드 존재를 실제 DB 연결이나 운영 완료로 표시하지 않는다.

[Step 02 임시 DB 실행·교체 방법](step02/README.md). 최종 DB 설계 대기 중에는 합성 SQLite를 사용하고, 공식 DB 완성 후 동일 검색 계약의 어댑터로 교체한다.

## 현재 범위

조합 규칙 → 선택 태그 OR 검색 → 공식 사업 내용·지역·대상·기간 검사 → 명백한 불일치 제외 → 추천 이유·미확인 조건 표시. 지역 U의 실제 원인 조사와 욕구 확인은 후속 확장이다.

I5 기준치·규칙별 조건은 미정이므로 임의의 수치를 하드코딩하지 않는다. 01은 외부에서 근거와 함께 평가한 true/false/null 조건을 받는다. 공식 DB의 태그·내용 검증 데이터가 연결되기 전에는 합성 시험만 가능하다.
