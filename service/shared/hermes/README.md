# HERMES 화면 자산

- hermi-0.png ~ hermi-4.png: 사용자가 제공한 view_design/헤르미 고화질.zip의 PNG. 원본 변경 없이 고정 이름으로 추출. 현재 화면에는 hermi-0.png 사용.
- provinces.geojson: https://raw.githubusercontent.com/southkorea/southkorea-maps/master/kostat/2018/json/skorea-provinces-2018-geo.json
  2026-10-25 취득. KOSTAT 2018 시도 경계. 원본 저장소: https://github.com/southkorea/southkorea-maps
  전국 시도 탐색을 위한 배경으로만 사용한다. 2025/2026 행정경계나 I5 집계 경계로 사용하지 않는다.
  영문 시도 명칭에서 현재 MOIS 시도 코드로 명시적인 탐색 대응표를 사용한다. 지수 공간 결합이 아니다.
- 상세 지도는 기존 shared/mock/districts.geojson과 기존 라이선스를 유지한다. 경계 없는 지역은 목록으로 안내한다.
- 색상은 사용자 제공 color_plate.jpg의 #00407E, #3C98DC, #A4C9A9, #FE9C8F, #FED47A, #FEF3E7, #E1EDF6 참고.
